Question 4

Use the Shapiro–Wilk test to assess whether Volume is normally distributed. Report the p-value and state whether the data are normally distributed.

Volume.aov <- aov(Volume ~ Volume, data = trees)
summary.aov(Volume.aov)
##             Df Sum Sq Mean Sq F value Pr(>F)
## Residuals   30   8106   270.2
Volume.resid <- residuals(Volume.aov)
shapiro.test(Volume.resid)
## 
##  Shapiro-Wilk normality test
## 
## data:  Volume.resid
## W = 0.88757, p-value = 0.003579

Thanks to the p-value resulting from this test being under 0.05, with a score of 0.003579, we can conclude that the data is NOT normally distributed thanks to there being signficant difference between data in this category.

Repeat the Shapiro–Wilk test for Girth. Report the p-value and state whether Girth is normally distributed.

##

## W = 0.94117, p-value = 0.08893

Despite Volume showcasing a clear difference between data thanks to a low p-value, the Shapiro-Wilk test reveals that values pertaining to the category of Girth are normally distributed, thanks to a p-value over 0.05, that of which being 0.08893.
