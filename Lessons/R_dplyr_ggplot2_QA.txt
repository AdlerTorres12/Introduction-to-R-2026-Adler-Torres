Q26. Count the characters in each species, largest group first.

Q27. In the class example, summarise(height = mean(height, na.rm = TRUE), min = min(height, na.rm = TRUE)) gave min = 175 instead of the real minimum. Why, and how do you fix it?
ANSWER 27:
|  Because the first line CREATES a column called height (the mean, 175), and the next line then
|  uses that new height instead of the original one. Fix: give the new columns different names.
|  starwars %>% summarise(mean_h = mean(height, na.rm = TRUE),
|                         min_h  = min(height, na.rm = TRUE),
|                         max_h  = max(height, na.rm = TRUE))

Q93. Difference between color and fill?
ANSWER 93:
|  color = points and lines/outlines; fill = the inside of areas (bars, histograms).

Q94. This code gives an error. What is wrong and how do you fix it?
    ggplot(mpg, aes(x = displ, y = hwy))
      + geom_point()
ANSWER 94:
|  The + starts the new line, so R thinks the first line is complete. The + must END the line:
|  ggplot(mpg, aes(x = displ, y = hwy)) +
|    geom_point()
|  (Same rule for the pipe: %>% goes at the END of a line.)

Q95. What is the order of layers in the ggplot2 'recipe'?
ANSWER 95:
|  data -> aesthetics -> geom -> stat/position (optional) -> coord (optional) -> facets (optional)
|  -> scales (optional) -> theme (optional); each layer is added with +.

Setup: coronary data read with readxl::read_excel("data/coronary.xlsx"); trees is built in.

Q96. Test whether tree Volume is normally distributed and interpret.
ANSWER 96:
|  shapiro.test(trees$Volume)
|  # W = 0.888, p = 0.0036 < 0.05 -> reject normality: Volume is NOT normally distributed.

Q97. Same for Girth.
ANSWER 97:
|  shapiro.test(trees$Girth)
|  # W = 0.941, p = 0.089 > 0.05 -> cannot reject normality: consistent with a normal distribution.

Q98. Spearman correlation between chol and dbp, and how to read it.
ANSWER 98:
|  cor.test(coronary$chol, coronary$dbp, method = "spearman", exact = FALSE)
|  # rho = 0.369, p < 0.001: significant positive monotonic relationship.
|  # rho > 0: both rise together; rho < 0: one rises as the other falls.
|  # exact = FALSE avoids warnings caused by tied ranks.

Q99. Test whether mean sbp differs by gender, and check the assumptions.
ANSWER 99:
|  anova_model <- aov(sbp ~ gender, data = coronary)
|  summary(anova_model)                          # F = 0.04, p = 0.842: no difference
|  shapiro.test(residuals(anova_model))          # normal residuals? p = 0.0001 -> violated
|  bartlett.test(sbp ~ gender, data = coronary)  # equal variances? p = 0.030 -> violated
